# GPT Researcher Workflow — Lobby NL Integration

## Overview

GPT Researcher is an autonomous AI research agent that performs multi-step web research. It can be used to generate actor seed data for the Lobby NL pipeline by researching specific organizations, people, or topics.

## Installation

```bash
pip install gpt-researcher
# Set your API key
export OPENAI_API_KEY="sk-..."
# Or use a local model via Ollama
export OLLAMA_BASE_URL="http://localhost:11434"
```

## Researching an Actor

```bash
# Research a single organization
gpt-researcher --query "CIDI Nederland lobby activiteiten Tweede Kamer" \
  --output data/input/cidi_gpt_research.json

# Research with specific instructions
gpt-researcher --query "Christenen voor Israël politieke invloed Nederland" \
  --instructions "Focus op parlementaire contacten, financiering, en publieke statements" \
  --output data/input/cvi_gpt_research.json

# Batch research from a query list
while IFS= read -r query; do
  gpt-researcher --query "$query" --output "data/input/gpt_$(echo $query | md5sum | cut -c1-8).json"
done < data/input/seed_queries.csv
```

## Converting GPT Researcher Output to manual_seeds.csv

The raw JSON output from GPT Researcher contains research findings. Convert it to the pipeline's actor seed format:

```python
import json
import csv
import uuid
from datetime import datetime, timezone

def convert_gpt_output_to_seeds(input_json: str, output_csv: str) -> None:
    """Convert GPT Researcher JSON output to manual_seeds.csv format."""
    with open(input_json, encoding="utf-8") as f:
        data = json.load(f)

    seeds = []
    # GPT Researcher returns research structured data
    # Adjust field names based on your GPT Researcher version
    content = data if isinstance(data, list) else data.get("research", [])
    
    if isinstance(content, str):
        # Single research result - parse entities from text
        content = [{"content": content}]
    
    for item in content:
        text = item.get("content", "") or str(item)
        # Extract potential actors from the research text
        # Use the pipeline's ActorExtractor for actual extraction
        seeds.append({
            "actor_id": f"seed_{uuid.uuid4().hex[:12]}",
            "name": item.get("title", "") or text[:100],
            "category": "unknown",
            "description": text[:500],
            "source_id": f"gpt_researcher_{datetime.now(timezone.utc).strftime('%Y%m%d')}",
            "url": item.get("url", ""),
            "notes": f"Generated by GPT Researcher on {datetime.now(timezone.utc).isoformat()}",
        })
    
    with open(output_csv, "w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=[
            "actor_id", "name", "category", "description",
            "source_id", "url", "notes"
        ])
        writer.writeheader()
        writer.writerows(seeds)
    
    print(f"Converted {len(seeds)} seeds to {output_csv}")

# Usage
convert_gpt_output_to_seeds(
    "data/input/cidi_gpt_research.json",
    "data/input/manual_seeds_gpt_researcher.csv",
)
```

## Integrating into the Pipeline

```bash
# 1. Run GPT Researcher on your queries
gpt-researcher --query "Israël lobby organisaties Nederland" \
  --output data/input/gpt_israel_lobby.json

# 2. Convert to seed format
python scripts/convert_gpt_output.py \
  data/input/gpt_israel_lobby.json \
  data/input/manual_seeds_gpt_researcher.csv

# 3. Run the Lobby NL pipeline with the enriched seeds
python -m src.main run-all --config-file config/sources.yaml
```

```bash
# Research all 8 core categories

```

## Limitations

- GPT Researcher output is AI-generated; always verify against source documents
- Rate limits on API keys apply
- Research depth and quality depend on prompt quality
- Use as seed discovery input, not as verified evidence
- Results should be run through the pipeline's extractor and classifier for proper sourcing
